# 동 → 풍무역 2번 출구 도보 경로 (설계)

## 무엇을

동을 고르면 **풍무역 2번 출구까지 걸어가는 길**을 지도에 그리고, 거리·예상 시간·힘듦을
같이 보여준다. 경로는 화려하게 흐르는 선으로 그린다.

정해진 것:

- 목적지는 **풍무역 2번 출구 하나**
- 힘듦은 **거리 기준** (고도·그늘은 안 쓴다)
- 지도에 **5호선(김포한강선) 예정 노선·정거장**도 표시

## 먼저 풀어야 하는 것

### 1. 마스크가 역까지 닿지 않는다

지금 `walk_mask.png` 는 (a) 범위를 대상 단지 둘레 200 m 로 잘랐고 (b) 차로 가운데를
파서 **연결망이 29조각**이다. 풍무역은 범위 밖이고, 도로를 건널 수가 없다.

- **범위**: 목적지를 포함하도록 넓힌다. 단지 둘레 200 m 에 더해 **역까지의 회랑**
  (역 지점 반경 200 m + 단지~역 직선 둘레 120 m)을 살린다. `make_walk.py` 의
  `RANGE_*` 에 목적지 좌표를 넣어 함께 살린다.
- **횡단보도**: 공개 데이터가 없다. 두 갈래로 간다.
  - `make_walk.py` 에 `CROSSINGS` 좌표쌍 목록을 두고 4 m 폭 띠를 그어 잇는다.
    도면과 카카오에서 눈으로 찍는다. 지구 안 교차로는 열 곳 남짓이라 손으로 적을 만하다.
  - 나머지는 `web/walk.html` 에서 브러시로 칠한다. 원래 그러라고 만든 도구다.
- 합격 판정은 `check_walk.mjs` 가 한다. 목적지를 역으로 두고 **모든 동에서 역까지
  경로가 나오는지**를 검사로 추가한다.

### 2. 풍무역 2번 출구 좌표

주소검색으로는 출구 번호가 안 나온다. `web/trace.html`(카카오 지도)에서 2번 출구를
찍어 좌표를 읽는다 — 이미 있는 도구다. 읽은 값은 `tools/make_routes.py` 의 상수로 둔다.

### 3. 5호선은 자료가 없다

김포한강선(5호선 연장)은 노선·정거장이 아직 확정 고시 단계라 **내가 좌표를 모른다.**
추측해서 그리면 안 된다. 둘 중 하나가 필요하다.

- 김포시 고시문·노선도에서 정거장 위치를 읽어 좌표를 준다
- 또는 카카오/브이월드에 그려진 게 있으면 `trace.html` 로 찍는다

받으면 `web/public/line5.json`(LineString + 정거장 Point)으로 두고 지도에 점선 + 역
마커로 그린다. **미확정임을 표시**한다 — 실측이 아니라 계획이다.

## 만드는 것

### `tools/make_routes.py` — 경로를 미리 굽는다

런타임에 A* 를 돌릴 이유가 없다. **동은 35개, 목적지는 하나**다. 빌드 때 다 계산해
폴리라인으로 내면 앱은 그리기만 하면 된다.

- 입력: `walk_mask.png`, `walk.json`, `buildings.json`
- `check_walk.mjs` 의 A*·출입점 로직을 파이썬으로 옮긴다(같은 격자·같은 8방향).
- 출력 `web/src/data/routes.json`:
  ```json
  { "to": { "name": "풍무역 2번 출구", "at": [126.xxx, 37.xxx] },
    "speedMps": 1.2, "crossingWaitS": 30,
    "routes": { "hoban3|401": { "line": [[lon,lat], ...], "metres": 812,
                                "crossings": 3, "seconds": 767 } } }
  ```
- 폴리라인은 3 m 허용오차로 단순화한다(격자 그대로면 점이 수천 개다).
- 동마다 출입점이 주 보행망에서 60 m 넘게 떨어지면 **실패로 알린다** — 마스크를 더
  손봐야 한다는 신호다.

### 시간과 힘듦

거리에서만 뽑는다. 근거를 코드에 적어 둔다.

| 값 | 쓰는 수치 | 근거 |
|---|---|---|
| 보행 속도 | 1.2 m/s (4.3 km/h) | 성인 평균. 신호 설계 기준 1.0 m/s 보다 빠르고, 분양 광고 관행 80 m/분(1.33)보다 느리다 |
| 신호 대기 | 횡단보도 1곳당 30 s | 대기 기댓값 ≈ 주기의 절반 |
| 소모 열량 | 3.5 MET × 체중 60 kg × 시간 | 평지 보통 걸음 |

힘듦은 등급으로 보여준다 — 숫자만으로는 감이 안 온다.

| 시간 | 표시 |
|---|---|
| ~5분 | 가깝다 |
| 5~10분 | 걸을 만하다 |
| 10~15분 | 조금 멀다 |
| 15분~ | 멀다 |

**분양 광고의 '역세권 도보 n분'과 다를 수 있다**는 문구를 같이 둔다. 광고는 직선거리에
80 m/분을 쓰고 신호 대기를 안 넣는다. 이 앱은 실제로 걷는 길을 따라 재고 대기도 넣는다.

### 앱 (`web/src/App.jsx`, `web/src/lib/route3d.js`)

동을 고르면(이미 있는 `sel`) 그 동의 경로를 지도에 얹는다.

- 소스 하나(`route`, GeoJSON LineString) + 레이어 셋. **`buildings-3d` 아래**에 넣어
  건물에 가려지게 한다 — 지면을 걷는 길이니 그게 맞다.
  1. 바깥 발광: 굵기 14, 흰색, 투명도 0.25
  2. 본선: 굵기 5, `line-gradient` 로 출발(주황) → 도착(파랑)
  3. 흐르는 점선: `line-dasharray` 를 매 프레임 굴려 흐르게 한다
- 진행 점: `Marker` 하나가 경로를 따라 3초에 완주하고 반복. 도착점에는 역 아이콘.
- 경로가 뜨면 카메라가 경로 전체를 담게 `fitBounds` 로 부드럽게 이동.
- 카드 하나로 요약: `401동 → 풍무역 2번 출구 · 812 m · 도보 13분 · 신호 3곳 · 걸을 만하다`
- 동 선택을 풀면 경로도 사라진다.

애니메이션은 `prefers-reduced-motion` 이면 정지선만 그린다.

### 5호선 표시

`line5.json` 을 받으면 얇은 점선 + 정거장 마커. **계획 노선**이라 실선으로 그리지 않고,
범례에 '계획'을 붙인다. 토지이용계획 스위치와 같은 자리에 켜고 끄는 스위치를 둔다.

## 검증

- `tools/check_walk.mjs` 에 **모든 동 → 역** 검사를 넣는다. 하나라도 길이 없으면 실패.
  경로 길이 분포(최소·중앙·최대)를 찍어 이상치를 눈에 띄게 한다.
- `tools/make_routes.py` 가 낸 거리와 `check_walk.mjs` 의 A* 거리가 1 m 안에서 같을 것.
- 브라우저: 동을 골랐을 때 선이 뜨고, 애니메이션이 돌고, 카드 숫자가 `routes.json` 과
  일치하고, 선택을 풀면 사라지는지 (`tools/smoke.mjs` 에 한 케이스 추가).
- 눈으로: 경로가 건물을 뚫지 않는지, 차로 한복판을 걷지 않는지.

## 순서

1. 풍무역 2번 출구 좌표 확인 → `make_walk.py` 범위에 회랑 추가
2. 횡단보도 `CROSSINGS` 를 찍어 넣고, 부족한 곳은 편집기로 칠한다
3. `check_walk.mjs` 에 모든 동 → 역 검사 추가 (여기서 초록불이 나와야 다음으로 간다)
4. `make_routes.py` 로 경로를 굽는다
5. 앱에 선·애니메이션·요약 카드
6. 5호선은 좌표를 받은 뒤 별도로
